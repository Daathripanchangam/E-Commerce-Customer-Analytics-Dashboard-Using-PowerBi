# E-Commerce-Customer-Analytics-Dashboard-Using-PowerBi

## Project Overview

The Customer Behavior Analytics Dashboard is a data analytics project developed to analyze customer demographics, purchasing patterns, product ratings, and shopping trends. The project integrates Python, SQL Server, and Power BI to transform raw customer data into meaningful business insights through interactive visualizations and KPI-driven reporting.

## Objectives

* Analyze customer purchasing behavior and preferences.
* Identify top-performing products based on customer ratings.
* Understand demographic trends such as gender distribution.
* Create interactive dashboards for data-driven decision-making.
* Generate actionable insights to improve customer engagement and business performance.

## Technologies Used

* Python
* SQL Server (SSMS)
* Power BI
* Pandas
* SQLAlchemy
* DAX

## Project Workflow

1. Data Collection and Loading

   * Imported customer dataset into Python.
   * Performed data cleaning and preprocessing.
   * Loaded data into SQL Server using SQLAlchemy.

2. Data Analysis

   * Wrote SQL queries to analyze customer behavior.
   * Calculated key metrics such as average ratings and product performance.
   * Aggregated and transformed data for reporting.

3. Dashboard Development

   * Connected Power BI to SQL Server.
   * Created interactive visualizations and KPIs.
   * Implemented filters and slicers for dynamic analysis.

## Dashboard Features

* Customer Demographics Analysis
* Gender Distribution Visualization
* Product Rating Analysis
* Top Purchased Products
* Customer Purchase Trends
* Interactive Filters and Slicers
* KPI Tracking and Business Insights

## Key Insights
